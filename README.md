# Напоминания: личный центр управления временем

PWA на Next.js для iPhone и любых других устройств: напоминания с повторами, свайпы между днями, календарь, часовые пояса, уведомления, синхронизация между устройствами и ИИ-ассистент, который сам создаёт и меняет напоминания.

## Возможности

- **Главный экран**: приветствие по времени суток, текущая дата, полоса недели с цветными точками и список дел на выбранный день, отсортированный по времени.
- **Свайпы**: влево — следующий день, вправо — предыдущий. Переход анимирован как перелистывание страницы. Жест фиксируется по одной оси, поэтому вертикальная прокрутка не ломается. На компьютере работают клавиши ← →.
- **Календарь**: любой месяц и год, точки на днях с напоминаниями, кнопка «Сегодня». При открытии приложения всегда показывается сегодняшний день.
- **Повторы**: не повторять, каждый день, неделю, месяц или год, выбранные дни недели, свой интервал («каждые 3 недели по Пн и Чт»), дата окончания или бесконечный повтор. 31-е число в коротком месяце переносится на последний день месяца, 29 февраля в невисокосный год — на 28-е.
- **Выполнение повторяющихся**: отмечается только текущий день, вся серия остаётся.
- **Редактирование серии**: «только это», «это и все последующие» (серия делится на две, история сохраняется) или «вся серия». Удаление работает так же.
- **Перенос**: быстрые варианты («через час», «вечером», «завтра», «в понедельник»…) или любая дата и время.
- **Временное отключение**: пауза для всей серии.
- **Разделы**: Сегодня, Предстоящие, Все (поиск и фильтры), Выполненные.
- **Цвета**: 7 пастельных оттенков. Карточка получает светлый фон, а более насыщенный акцент идёт на чекбокс и время. Отдельная палитра для тёмной темы.
- **Часовые пояса**: автоматически по устройству или вручную, любой пояс мира. Подробности ниже.
- **Темы**: светлая, тёмная, системная, без вспышки при загрузке.
- **Уведомления**: в момент события или заранее (5 минут … неделя), отдельное время для дел без времени, звук.
- **ИИ-ассистент**: «Напомни в пятницу в 10 позвонить маме», «Что у меня завтра?», «Перенеси спортзал на вечер». У каждого действия ассистента есть кнопка «Отменить».
- **Данные**: работает офлайн (IndexedDB), экспорт и импорт в JSON, синхронизация через Supabase в реальном времени.

## Как устроены часовые пояса

Каждое напоминание хранит **время по часам** (`date` + `time`) и один из двух режимов:

| Режим | Пример | Поведение в поездке |
|---|---|---|
| **Местное** (`tz = null`, по умолчанию) | «Таблетки в 09:00» | В Токио сработает в 09:00 по Токио |
| **Закреплённый пояс** (`tz = "Europe/Athens"`) | «Созвон в 10:00 по Афинам» | В Нью-Йорке покажется как 03:00 с пометкой «10:00 Athens» |

Повторы считаются по часам и только потом переводятся в абсолютное время, поэтому 09:00 остаётся 09:00 и после перехода на летнее или зимнее время. Несуществующее время (например, 03:30 в ночь перевода часов вперёд) сдвигается вперёд. Это покрыто тестами (`tests/core.test.ts`).

## Архитектура

```
app/
  page.tsx                  клиентское приложение (SSR отключён: данные живут на устройстве)
  layout.tsx                метаданные PWA, тема до первой отрисовки
  globals.css               дизайн-система (CSS-переменные, светлая и тёмная тема)
  api/assistant/route.ts    прокси к Claude API с инструментами (tool use)
  api/push/dispatch/route.ts  отправка Web Push по расписанию (pg_cron)
src/
  core/        чистая логика без зависимостей, покрыта тестами
    dates.ts         календарная математика и часовые пояса на Intl API
    recurrence.ts    движок повторов
    occurrences.ts   развёртка серий в конкретные дни, расчёт следующего уведомления
    mutations.ts     создание, правки с областью действия, перенос, выполнение
    assistant-tools.ts  описание инструментов ИИ и системный промпт
  state/       хранилище, IndexedDB, синхронизация с Supabase, действия, клиент ассистента
  notify/      уведомления (в приложении и Web Push)
  ui/          интерфейс
public/sw.js   service worker: офлайн-оболочка, push, клики по уведомлениям
supabase/schema.sql  таблицы, RLS, realtime, cron
```

**Синхронизация (local-first).** Любое изменение сразу сохраняется на устройстве и встаёт в очередь (outbox). При наличии сети очередь отправляется в Supabase. Чужие изменения приходят через realtime и полную подгрузку при открытии, фокусе и восстановлении сети. Конфликты решаются по принципу «побеждает последняя запись» (`updatedAt`). Удаление мягкое (`deleted_at`), поэтому доходит до всех устройств.

**ИИ-ассистент.** Сервер только передаёт запрос в Claude вместе с описанием инструментов (`create_reminder`, `list_reminders`, `find_reminders`, `update_reminder`, `complete_reminder`, `postpone_reminder`, `delete_reminder`). Сами инструменты выполняются в браузере через те же функции, что и кнопки интерфейса. Поэтому ассистент работает и без облака, а его изменения синхронизируются как обычные.

> Вместо Tailwind используется собственная дизайн-система на CSS-переменных: так проще точно настроить пастельную палитру, тёмную тему и iOS-детали. Для дат не нужна внешняя библиотека: всё сделано на встроенном `Intl` с полной поддержкой IANA-поясов.

## Запуск локально

```bash
npm install
cp .env.example .env.local   # можно оставить пустым: приложение будет хранить данные на устройстве
npm run dev                  # http://localhost:3000
npm test                     # тесты логики повторов и часовых поясов
```

## Деплой на Vercel

### 1. Базовая версия (5 минут)

1. Загрузите папку в GitHub-репозиторий.
2. На [vercel.com](https://vercel.com): **Add New → Project**, выберите репозиторий и нажмите **Deploy**.
3. Готово: приложение работает и хранит данные на устройстве.

### 2. Синхронизация между устройствами (Supabase)

1. Создайте проект на [supabase.com](https://supabase.com).
2. **SQL Editor**: вставьте и выполните `supabase/schema.sql`.
3. **Authentication → Sign In / Providers → Email**: включено по умолчанию.
4. **Authentication → Email Templates → Magic Link**: добавьте в шаблон код, чтобы вход шёл по 6-значному коду (на iPhone так удобнее, чем по ссылке):
   ```html
   <h2>Код для входа</h2>
   <p style="font-size:28px;letter-spacing:6px"><b>{{ .Token }}</b></p>
   ```
5. **Authentication → URL Configuration**: в Site URL укажите адрес приложения на Vercel.
6. В Vercel → **Settings → Environment Variables** добавьте значения из **Project Settings → API**:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `SUPABASE_SERVICE_ROLE_KEY` (секретный, нужен только серверу)
7. Сделайте **Redeploy**, затем в приложении войдите по email: **Настройки → Аккаунт**.

### 3. Push-уведомления при закрытом приложении

1. Сгенерируйте ключи: `npx web-push generate-vapid-keys`.
2. Добавьте в Vercel: `NEXT_PUBLIC_VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT=mailto:вы@почта`, а также `CRON_SECRET` (любая длинная случайная строка). Сделайте Redeploy.
3. В Supabase: **Database → Extensions**, включите `pg_cron` и `pg_net`.
4. Выполните cron-блок в конце `supabase/schema.sql`, подставив свой адрес и `CRON_SECRET`. Сервер будет проверять напоминания каждую минуту.
5. На iPhone установите приложение на экран «Домой», войдите в аккаунт и включите уведомления в настройках.

> Почему не Vercel Cron: на бесплатном тарифе Vercel cron запускается не чаще раза в день. `pg_cron` в Supabase бесплатно работает раз в минуту.

**Честно о доставке.** Пока приложение открыто, уведомления показывает само приложение. При закрытом приложении их доставляет Apple или Google через Web Push. На iPhone это работает с iOS 16.4 и только для приложения, установленного на экран «Домой». Доставку контролирует система (режимы фокусировки, экономия энергии), поэтому 100% гарантии нет.

### 4. ИИ-ассистент

1. Получите ключ на [console.anthropic.com](https://console.anthropic.com).
2. Добавьте в Vercel `ANTHROPIC_API_KEY`. Модель можно сменить через `ANTHROPIC_MODEL` (по умолчанию `claude-sonnet-5-5`).
3. Защитите ключ от чужих: если подключён Supabase, ассистент доступен только вошедшему пользователю. Без Supabase задайте `ASSISTANT_PASSCODE` и введите тот же код в **Настройки → ИИ-ассистент**.

## Установка на iPhone

Safari → откройте адрес приложения → **Поделиться** → **На экран «Домой»**. Приложение откроется на весь экран, с иконкой и без интерфейса браузера.

## Идеи для развития

- Голосовой ввод в ассистенте, утренняя сводка от ассистента push-уведомлением.
- Подзадачи и чек-листы внутри напоминания.
- Категории и теги с фильтрами, виджет «Сегодня».
